# Reference panels

Large genomic reference datasets are deliberately not committed to Git.

A production deployment must mount exact, immutable releases of:

- IGSR / 1000 Genomes for broad modern variation
- Simons Genome Diversity Project where its data access and reuse terms permit
- Allen Ancient DNA Resource for reviewed ancient-population models

For each panel record the release, source URL, checksum, genome build, sample exclusions, reuse terms, required citation, review date and model purpose. Never silently mix genome builds or treat a reference label as a biological race. Regional gaps and panel imbalance must appear in every report.
